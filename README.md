# @voxmate/voxmate

Voxmate base SDK — engine API typings (`types.d.ts`), intrinsic wrappers (`voxmate.ts`), and core utilities (`utility/`) for authoring voxlets: audio-first apps for the Voxmate platform.

Voxlets import this surface as `voxmate/voxmate`, `voxmate/types`, and `voxmate/utility/*`; the Voxmate build pipeline resolves those aliases to this package.

```
npm install @voxmate/voxmate
```
